# React DateKit Monorepo

The framework-first, zero-dependency date and time picker for modern React (React 18 & 19).

## Packages & Apps

- **[`packages/react-datekit`](./packages/react-datekit)**: Core NPM package (`react-datekit`).
- **[`apps/docs`](./apps/docs)**: Documentation website and interactive playground built with Fumadocs and Next.js.

## Getting Started

```bash
# Install dependencies
pnpm install

# Run documentation & playground dev server (localhost:3000)
pnpm dev

# Build the react-datekit library package
pnpm build

# Run Vitest test suite
pnpm test

# Typecheck TypeScript
pnpm typecheck
```
