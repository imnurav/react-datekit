# Introduction

**React DateKit** is a production-ready, framework-first date and time picker library engineered exclusively for modern React (React 18 & 19). It provides unified components that seamlessly adapt between inline calendars, popovers, multi-month ranges, and time selection.

---

## Why React DateKit?

Most React date pickers suffer from one of three problems:

1. **Heavy date runtime dependencies** — Libraries bundling `moment` or `date-fns` inflate your bundle size by 50KB–200KB.
2. **Fragmented component APIs** — Forcing developers to install different components for single dates, ranges, and time pickers.
3. **Poor touch & keyboard support** — Lack of proper WAI-ARIA grid navigation and clunky mobile popovers.

React DateKit solves this with **0 runtime dependencies**, relying 100% on native JavaScript `Date` math and cached `Intl.DateTimeFormat` instances.
