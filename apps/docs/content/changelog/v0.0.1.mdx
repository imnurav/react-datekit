# v0.0.1 Release Notes

_Released: September 2026_

Version `0.0.1` marks the initial public release of **React DateKit** — a framework-first, zero-dependency date and time picker built exclusively for modern React (React 18 & 19).

---

### Key Features

- **Unified Component API** — One `<DatePicker />` component adapts between single date, range, datetime, multiple dates, month, and year views.
- **0 External Date Dependencies** — Uses 100% native JavaScript Date math and cached `Intl.DateTimeFormat` instances. Zero Moment or date-fns overhead.
- **Integrated Time Selection** — 12-hour (with AM/PM segmented pills) and 24-hour time columns, optional seconds selection (:ss), and configurable minute/second steps.
- **Built-in Presets** — 15+ presets (`today`, `yesterday`, `last7Days`, `thisMonth`, etc.) with docking placements (left, right, top, bottom).
- **Multi-Month Display** — Render 1 to 4 calendar panels side-by-side or stacked vertically.
- **WAI-ARIA Accessibility** — Full keyboard grid navigation with Arrow keys, PageUp/PageDown, Home, End, and roving tab indices.
- **Native Internationalization & RTL** — Full BCP 47 locale formatting and bidirectional layout support.

---

## Migration Guide

Initial release. Install via your package manager:

```bash
npm install react-datekit
```
